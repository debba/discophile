## Easier synchronization through your account

- Updated Connect instances can associate your computers when you sign in to the same account, without exchanging a recovery code. New connections are selected automatically within your plan's allowance; you can change the selection in Connect settings.
- To migrate an existing configuration, open a previously paired computer with this version once. Other computers can then recover the synchronization key through the account.
- In this mode, Connect stores an encrypted recovery bundle and can recover its keys. The instance operator is trusted with key custody. Older Connect instances continue using private recovery-code pairing.

## Choose where to listen

- Open **Playback devices** from the player bar to send playback to another computer or choose **Continue here** to bring it to this one.
- Transfers preserve the music queue or audiobook position, playback speed and paused state. The source keeps playing until the destination confirms it is ready; failures and timeouts leave the source playing.
- Audiobookshelf can retrieve a book that the destination has never browsed before. Both computers still need access to the corresponding server, and receivers must be open and online. Connect does not relay audio.

## Audiobookshelf on your other computers

- A selected Audiobookshelf connection can synchronize its saved password inside the encrypted configuration. Each computer signs in independently and keeps its own session tokens; refresh tokens are never copied.
- Existing Audiobookshelf connections need one new sign-in on the source computer to save the password for automatic sign-in elsewhere. A different local Audiobookshelf account is preserved.
- Paused audiobook transfers stay paused while files are prepared, without briefly starting audio.

## More accessible account menus

- Larger 15-point menu text, 44-point rows, consistent 12-point outer margins and aligned icon columns.
- A stronger selected-library indicator, complete library names for assistive technology and an explicit checked state. Long names truncate visually without widening the menu.
- Visible keyboard focus, arrow-key navigation and focus restoration when closing the library menu with Escape. Focus outlines remain visible inside scrolling lists.
- Verified in light and dark themes and with text enlarged to 150%.

## Compatibility

- Account-based recovery requires a Connect service advertising `account-sync` version 1. Instance operators must apply the account-sync database migration and deploy the matching backend; installing the desktop app alone does not enable the service extension.
- Update all paired desktop clients to 0.1.4 before synchronizing Audiobookshelf passwords, so each client understands the extended configuration records.
- Free retains two paired computers and one synchronized connection. Playback handoff and remote controls require Connect or Supporter.
- This release updates the desktop app and web player. iPhone service integration is unchanged.
