# Discophile 1.0.3

- Audiobookshelf streaming recovers automatically when the access token embedded in an audio URL expires. Desktop and web reload the current file at the listening position only after the token changes. Android retries a rejected media request once with the renewed token and preserves its Range.
- Pausing during desktop token renewal keeps playback paused; ordinary network and format failures retain their existing error behavior.
- The iPhone app is distributed separately through the App Store. This release contains desktop packages and the Android APK.

Existing accounts, downloads and application identifiers are retained. Android updates use the same signing certificate as 1.0.2, with version code 10.
