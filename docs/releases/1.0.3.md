# Discophile 1.0.3

Discophile 1.0.3 fixes audiobook streaming that could stop when an Audiobookshelf access token expired. Desktop/web reload the current file at the listening position after the token changes. Android retries a rejected media request once with the renewed token while retaining the requested audio range. Pausing during desktop renewal keeps playback paused.

**Android signing change:** Android 1.0.3 (10) uses a new signing certificate. Installations signed with the earlier release or development key require uninstalling and reinstalling. Uninstalling removes app-local settings/accounts, downloaded audio and unsynchronized progress. Verify server progress and retain connection/recovery details before removing the old app. Read [the migration instructions](https://github.com/debba/discophile/releases/download/v1.0.3/MOBILE-INSTALLATION.md). New installations do not need this migration; future updates will use the new key.

Packages: signed Android APK for Android 8 or later; macOS universal (Intel and Apple Silicon), signed and notarized; Windows x86_64; Linux archive, Debian package and AppImage; web player image and Helm chart. The iPhone app is distributed separately through the App Store.
