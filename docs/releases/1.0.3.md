# Discophile 1.0.3

Discophile 1.0.3 fixes audiobook streaming that could stop when an Audiobookshelf access token expired. The current file reloads at the listening position after the token changes, including when the client had already renewed its session. Pausing during renewal keeps playback paused.

Packages: macOS universal (Intel and Apple Silicon), signed and notarized; Windows x86_64; Linux archive, Debian package and AppImage; web player image and Helm chart.

No Android APK is included in these assets. The iPhone app is distributed separately through the App Store.
