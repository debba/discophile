## New

- **Update without leaving Discophile.** Download, verify, install and restart from one button, with progress shown in the app.
- A compact notification announces available updates at launch. Choose **Later** to dismiss it; the toolbar icon remains available when you are ready.
- **Check for Updates…** is now available in the native macOS application menu.
- After an update, a Markdown changelog shows what changed, including any releases you skipped. Notes are saved before restarting so they remain available offline.

## Improved

- Redesigned **Settings → About → Updates** with a clear version transition, a primary install action, expandable release notes and a separate automatic-check setting.
- Release notes support headings, lists, bold and italic text, code and links to merged pull requests.
- Improved keyboard navigation, focus indicators, screen reader announcements, contrast and layouts at larger text sizes.
- GitHub is now at the bottom of the sidebar and in **Settings → About**. The post-update changelog includes website and GitHub shortcuts.

## Reliability

- Update packages are checked against the release's SHA-256 manifest before installation. macOS bundles are also checked for their version and signing identity.
- Installation waits for Discophile to exit and keeps the previous version for recovery if replacement or restart fails.
- Draft releases, prereleases and unmerged pull requests are excluded from the installed changelog.

**Updating from 0.1.1:** Download and install this release once to enable the new in-app updater for future versions.
