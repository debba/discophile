## Connect reconnects after a refused registration

- A computer whose device registration was revoked from another device now registers again automatically when account sync is on, instead of staying stuck on an error. It retries once with a fresh device identity, so a repeated refusal still shows the error.
- Without a vault on the account, pairing starts from a fresh identity, so keys of a deleted vault can no longer block creating a new one.
- **Forget this registration and pair again** is now also offered next to the recovery code import when pairing fails, so you can start over without signing out. English and Italian are included.

## Compatibility

- No Connect server deployment or entitlement changes are needed.
